# Preserving-Ancient-History-with-AI-Introducing-Aethel-Tamil-
**Aethel-Tamil (ஆதித்தமிழ்):** An end-to-end AI pipeline for digitizing and translating ancient Chola-era Tamil stone inscriptions. Uses OpenCV preprocessing, a PyTorch ResNet-18 OCR engine, and Gemini AI for lexical correction, word spacing, and English translation. Built with FastAPI, Streamlit, and local failsafe caching.
